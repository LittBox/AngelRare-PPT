- **设计稿尺寸**：1920×1080（16:9）
- **每页边距**：建议 80px-100px（参考设计稿的实际间距）
- **栅格系统**：12 列 / 4 列网格
- **卡片圆角**：12px-20px（设计稿使用较多）

- **强调动效**：仅用于关键数据和高亮元素
